# Step 134：游客装备封面保存失败问题修复

## 一、问题描述

### 1.1 现象

游客态保存装备时：
- **无封面**：保存成功，返回列表正常显示
- **有封面**：保存成功（toast "装备已入库"），但返回列表显示空态

### 1.2 根因分析

**问题链路**：
1. `onPickPhoto()` 调用 `compressToDataURL(tempPath)` 读取压缩后的图片文件
2. `compressToDataURL()` 直接读取文件为 base64，未进一步压缩
3. dataURL 可能非常大（几十 KB 到几百 KB）
4. `gearStore.create()` 调用 `upsertPendingGear(item)` 写入 storage
5. **`upsertPendingGear()` 返回 `false`（写入失败），但调用方未检查返回值**
6. `this.gears = getPendingGears()` 读取到空数组或旧数据
7. Toast 显示"装备已入库"（保存逻辑本身没报错）
8. 返回列表页后，`onShow` 触发 `fetchList()` → 读取空数组 → 显示空态

### 1.3 代码定位

| 文件 | 行号 | 问题 |
|------|------|------|
| `miniapp/src/utils/index.ts` | L234-248 | `compressToDataURL()` 未压缩，直接读取 |
| `miniapp/src/pages/gear/form.vue` | L207 | 调用 `compressToDataURL()` |
| `miniapp/src/stores/gear.ts` | L106 | `upsertPendingGear()` 返回值未检查 |
| `miniapp/src/stores/gear.ts` | L126 | `updatePendingGear()` 返回值未检查 |
| `miniapp/src/stores/gear.ts` | L146 | `removePendingGear()` 返回值未检查 |
| `miniapp/src/services/pendingRepo.ts` | L38-50 | `persist()` 已区分"空间不足"和"写入失败"，但返回 boolean |

---

## 二、修复方案

### 2.1 核心原则

1. **压缩图片**：存储前先压缩，减少 dataURL 大小
2. **检查写入结果**：storage 写入失败时抛错，不再静默继续
3. **区分错误类型**：空间不足 vs 写入失败，提示不同文案

### 2.2 改动文件

| 文件 | 改动内容 |
|------|---------|
| `miniapp/src/utils/index.ts` | 新增 `compressImageToDataURL()` 函数，先压缩再转 dataURL |
| `miniapp/src/pages/gear/form.vue` | 使用 `compressImageToDataURL()` 替换 `compressToDataURL()` |
| `miniapp/src/stores/gear.ts` | 检查 `upsertPendingGear/updatePendingGear/removePendingGear` 返回值，失败时抛错 |

## 三、详细设计

### 3.1 新增 `compressImageToDataURL()` 函数

**文件**：`miniapp/src/utils/index.ts`

```typescript
/**
 * 压缩图片并转为 dataURL（用于游客态本地存储）
 * 
 * 流程：uni.compressImage 压缩 → uni.getFileSystemManager 读取为 base64
 * 压缩参数：最大宽度 800px，质量 70%，平衡清晰度与存储大小
 */
export function compressImageToDataURL(
  filePath: string,
  options?: { width?: number; quality?: number }
): Promise<string> {
  return new Promise((resolve, reject) => {
    const { width = 800, quality = 70 } = options || {};
    
    uni.compressImage({
      src: filePath,
      quality,
      compressedWidth: width,
      success: (res) => {
        const fs = uni.getFileSystemManager();
        fs.readFile({
          filePath: res.tempFilePath || filePath,
          encoding: "base64",
          success: (r) => resolve(`data:image/jpeg;base64,${r.data as string}`),
          fail: (err) => reject(new Error(err.errMsg || "图片读取失败")),
        });
      },
      fail: (err) => reject(new Error(err.errMsg || "图片压缩失败")),
    });
  });
}
```

## 五、风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 压缩后图片质量下降 | 低 | 800px/70% 质量对缩略图显示足够 |
| 压缩失败导致无法保存 | 低 | `compressImageToDataURL` 失败时会 reject，form.vue 会 toast 错误 |
| 现有功能回归 | 低 | 无封面场景 unchanged，仅修改有封面场景 |
| 测试覆盖不足 | 中 | 需手动测试所有场景 |
