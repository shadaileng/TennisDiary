# 96：小程序大满贯球场主题

## 一、背景与目标

### 1.1 现状问题

| 问题 | 严重度 | 说明 |
|------|:------:|------|
| 「青柠主题」开关无效 | 🔴 | `mine.vue` 的开关只切换 `useLimeTheme` 并持久化，全端无任何代码读取该值消费样式，开关形同虚设 |
| 强调色硬编码散落 | 🔴 | 青柠色系（`#C8DA2B`/`#A8B822`/`#F0F5CE` 及 `rgba(200,218,43,…)`）硬编码在约 17 个文件、30+ 处（SCSS 变量、hex/rgba 字面量、TS 常量、命令式 API 参数） |
| 无主题扩展能力 | 🟡 | 设计 token（`tokens.scss`）只有固定色值，无法运行时切换主题 |

### 1.2 目标

1. **修复开关无效**：让「我的」页主题选项真正生效，全端强调色跟随切换
2. **大满贯球场主题**：提供 4 套球场主题——青柠（品牌默认）/ 澳网硬地蓝 / 法网红土 / 温网草绿，贴合网球产品调性
3. **主题驱动机制**：SCSS 硬编码 → CSS 变量（`page-meta` 按页注入），Canvas 图表与命令式 API（`uni.showActionSheet`/`uni.showModal`）跟随主题
4. **旧数据兼容**：旧 storage 的 `useLimeTheme: boolean` 无损迁移到新 `theme` 字段

## 二、主题设计

### 2.1 主题注册表

每个主题由 9 个语义 Token 组成。**核心设计隐喻：网球恒青柠、球场随主题**——

- 🎾 **网球**（强调系）：`accent`/`accent-dark`/`accent-soft`/`accent-rgb` 四主题**恒定青柠**。按钮、标签、图表、进度条等强调元素不随主题漂移，保持品牌识别与对比度（青柠为深/浅球场底色上的共同高对比色）
- 🏟️ **球场**（背景/卡片系）：`page-bg`/`card`/`border`/`hero-a`/`hero-b` 随球场取色，营造场地氛围

| key | 名称 | 球场 | accent(恒) | accent-dark(恒) | accent-soft(恒) | accent-rgb(恒) | page-bg | card | border | hero-a | hero-b |
|:---:|:----:|:-----|:------:|:-----------:|:-----------:|:----------:|:-------:|:------:|:------:|:------:|:------:|
| `lime` | 青柠 | 品牌默认·硬地 | `#C8DA2B` | `#A8B822` | `#F0F5CE` | `200,218,43` | `#F2F2EF` | `#FFFFFF` | `#E7E9DF` | `#242B1F` | `#3A4433` |
| `ao` | 澳网 | 硬地·蓝 | 同上 | 同上 | 同上 | 同上 | `#D8E5F4` | `#F0F7FD` | `#BDD0E8` | `#16293F` | `#2C4A6E` |
| `french` | 法网 | 红土 | 同上 | 同上 | 同上 | 同上 | `#E2CABC` | `#F8EDE5` | `#D5BAA8` | `#3C231A` | `#5E382A` |
| `wimbledon` | 温网 | 草地 | 同上 | 同上 | 同上 | 同上 | `#D0E0C9` | `#EDF5E9` | `#B8CFAB` | `#20301C` | `#3B5226` |

**强调系（网球，恒定青柠）**：
- `accent`：主强调色（按钮、高亮、图标、图表）
- `accent-dark`：深强调色（文字强调、`confirmColor`、switch 颜色）
- `accent-soft`：浅强调色（选中底色、光斑、标签底色）
- `accent-rgb`：RGB 三元组，用于 `rgba(var(--color-accent-rgb), 0.x)` 半透明场景

**背景/卡片系（球场，随主题）**：
- `page-bg`：页面背景 + 次级表面（Seg/Tag/Stepper/MoneyToggle 底色），按球场明显取色，是主题基调的最大面积
- `card`：卡片表面（日记/装备/统计/表单卡片、菜单卡），浅球场色调（非纯白），与 `page-bg` 形成可感知色差
- `border`：分隔线/卡片边框，取 `page-bg` 与 `card` 之间的中间调
- `hero-a` / `hero-b`：深色大卡（资料卡、教练 hero、装备无图封面）渐变，球场深色调
- 弹层/遮罩（Popup、ActionSheet、Loading）与 hero 卡上的白色按钮**保持纯白**，保证模态可读性

### 2.2 作用范围

主题作用于**球场类（背景/卡片/边框）** 元素，**强调类保持青柠恒定**；中性文字（橄榄 `$color-olive`、墨色 `$color-ink`、橄榄浅 `$color-olive-light`）保持不变以保证可读性：

- 🏟️ 随主题：页面背景、次级表面（Seg/Stepper/Tag/MoneyToggle/Empty 底色）、卡片表面、分隔线/边框、深色大卡（我的页资料卡、教练 hero 卡、装备无图封面）渐变
- 🎾 恒青柠：按钮/主操作背景、图标高亮、进度条、标签、空状态、加载指示器、Canvas 图表、命令式弹层按钮颜色（`confirmColor`）、switch

> 设计依据：材质/语义 Token 最佳实践——主题主要改变**背景与表面**（视觉感知大头）；同时借鉴网球运动的双元素隐喻（球与球场），让品牌强调色稳定、场地氛围随主题切换。

## 三、技术方案

### 3.1 数据层：settings store 改造与迁移

`src/stores/settings.ts`：

```typescript
export type ThemeKey = "lime" | "ao" | "french" | "wimbledon";

export interface ThemePalette {
  key: ThemeKey
  name: string
  desc: string
  accent: string      // 主强调色
  dark: string        // 深强调色
  soft: string        // 浅强调色
  rgb: string         // 强调色 RGB 三元组
  pageBg: string      // 页面背景 / 次级表面
  border: string      // 分隔线 / 边框
  heroA: string       // 深色大卡渐变起
  heroB: string       // 深色大卡渐变止
}

/** 主题注册表（唯一数据源，store 与「我的」页选择 UI 共用） */
export const THEMES: ThemePalette[] = [ /* 四套球场主题 */ ];

// state: useLimeTheme: boolean  →  theme: ThemeKey
// getter: themePalette: ThemePalette  （按当前 theme 查找）
// action: setTheme(key: ThemeKey) 持久化
```

- `init()` 兼容旧数据：读到的旧 storage 若含 `useLimeTheme`，**忽略其值**（旧值从未生效），默认 `theme = "lime"`；`persist()` 写入新字段 `theme`，不再写入 `useLimeTheme`
- 非法 theme 值（如手工篡改 storage）回退 `"lime"`

### 3.3 page-meta 按页注入

微信小程序支持 `<page-meta page-style>` 将内联样式写到 page 节点，**CSS 变量沿组件树继承（含自定义组件）**，天然覆盖各页面根元素。`page-meta` 的 `background-color` 属性同步窗口背景色（下拉/回弹区域），避免与页面背景出现色差。composable 统一生成：

`src/composables/useTheme.ts`：

```typescript
export function useThemeStyle() {
  const settings = useSettingsStore();
  const themeStyle = computed(() => {
    const t = settings.themePalette;
    return `--color-accent:${t.accent};--color-accent-dark:${t.dark};`
      + `--color-accent-soft:${t.soft};--color-accent-rgb:${t.rgb};`
      + `--color-page-bg:${t.pageBg};--color-card:${t.card};--color-border:${t.border};`
      + `--color-hero-a:${t.heroA};--color-hero-b:${t.heroB}`;
  });
  /** 窗口背景色（page-meta background-color 需十六进制值） */
  const themeBg = computed(() => settings.themePalette.pageBg);
  return { themeStyle, themeBg };
}
```

每个页面模板顶部加一行（**11 个页面**）：

```html
<page-meta :page-style="themeStyle" :background-color="themeBg" />
```

接入页面清单：

### 3.4 硬编码颜色替换清单

统一替换规则（背景/卡片/边框系）：

- `$color-lime` → `var(--color-accent, #C8DA2B)`
- `$color-lime-dark` → `var(--color-accent-dark, #A8B822)`
- `$color-lime-soft` → `var(--color-accent-soft, #F0F5CE)`
- `rgba(200, 218, 43, α)` → `rgba(var(--color-accent-rgb, 200, 218, 43), α)`
- 页面背景 / 次级表面 `$color-paper`、`#f2f2ef` → `var(--color-page-bg, #F2F2EF)`
- 卡片表面 `$color-white`（页面级卡片） → `var(--color-card, #FFFFFF)`；弹层/遮罩（Popup、ActionSheet、Loading）与 hero 卡上的按钮**保持纯白不动**
- 分隔线 `solid/dashed $color-paper` → `var(--color-border, #E7E9DF)`
- 深色大卡渐变 `linear-gradient(135deg, #242b1f, #3a4433)` → `linear-gradient(135deg, var(--color-hero-a, #242B1F), var(--color-hero-b, #3A4433))`

**页面 SCSS（8 个）**：`share/share.vue`、`coach/report.vue`、`coach/coach.vue`、`coach/analyze.vue`、`stats/stats.vue`、`gear/gear.vue`、`diary/diary.vue`、`diary/form.vue` —— 按规则替换 `$color-lime` 系列、`rgba(200,218,43,…)`、页面背景与分隔线（含 mine.vue、profile-edit.vue 光斑/背景、gear/form.vue 虚线边框）。

### 3.5 Canvas 图表与命令式 API 主题

CSS 变量不作用于 `<canvas>` 绘制内容与 JS 侧 API 参数，需单独处理：

| 位置 | 现状 | 改造 |

### 3.6 「我的」页主题选择 UI

将「青柠主题」switch（`mine.vue:71-78`）改为**菜单项 + 主题选择弹层**：
