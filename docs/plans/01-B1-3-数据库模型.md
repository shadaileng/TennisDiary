# Step B1-3：数据库模型

## 一、目标

创建 7 个 SQLAlchemy ORM 模型，严格对照原项目 `types.ts` 类型定义，涵盖用户、日记、装备、体重、分析、打卡、发布。

## 二、前置条件

- B1-2 完成（`Base` / `engine` 可用）

## 三、参考来源

对照 `/workspace/docs/reference/tennis-diary/src/types.ts` 中的接口定义。

## 四、详细执行步骤

### 4.1 User 表 — `app/models/user.py`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | Integer | PK, autoincrement |
| openid | String(128) | NOT NULL, unique, index |
| nickname | String(64) | default "" |
| avatar_url | String(512) | default "" |
| created_at | DateTime | server_default=func.now() |
| updated_at | DateTime | server_default=func.now(), onupdate=func.now() |

### 4.2 Diary 表 — `app/models/diary.py`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | Integer | PK |
| user_id | Integer | NOT NULL, index |
| date | String(10) | NOT NULL (YYYY-MM-DD) |
| time | String(5) | default "" (HH:mm) |
| type | String(16) | default "训练" |
| duration | Integer | default 0 |
| intensity | Integer | default 3 (1-5) |
| mood | Integer | default 3 (1-5) |
| costs | Text | default "[]" (JSON) |
| gears | Text | default "[]" (JSON) |
| notes | Text | default "" |
| created_at | Float | default 0 |
| updated_at | DateTime | onupdate |

提供 `get_costs()` / `get_gears()` 辅助方法做 JSON 反序列化。

### 4.3 Gear 表 — `app/models/gear.py`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | Integer | PK |
| user_id | Integer | NOT NULL, index |
| category | String(32) | default "" |
| name | String(128) | default "" |
| buy_date | String(10) | default "" |
| price | Float | default 0 |
| feeling | Text | default "" |
| photo | Text | default "" (dataURL 或文件路径) |
| created_at | Float | default 0 |
| updated_at | DateTime | onupdate |

### 4.4 WeightRecord 表 — `app/models/weight.py`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | Integer | PK |
| user_id | Integer | NOT NULL, index |
| date | String(10) | NOT NULL |
| weight | Float | default 0 |
| bust | Float | nullable |
| waist | Float | nullable |
| hip | Float | nullable |
| created_at | Float | default 0 |
| updated_at | DateTime | onupdate |

### 4.5 Analysis 表 — `app/models/analysis.py`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | Integer | PK |
| user_id | Integer | NOT NULL, index |
| date | String(10) | NOT NULL |
| kind | String(16) | default "综合" |

| score | Float | default 0 |

### 4.6 Checkin 表 — `app/models/checkin.py`

| 字段 | 类型 | 约束 |

### 4.7 Post 表 — `app/models/post.py`

| 字段 | 类型 | 约束 |

## 五、验证

在 `app/main.py` 中添加模型导入 + 自动建表：

```python
from app.core.database import engine, Base
from app.models import user, diary, gear, weight, analysis, checkin, post

Base.metadata.create_all(bind=engine)
```

然后用 SQLite 命令行或 Python 检查所有表是否创建成功。
