# Step 114：Admin 文件预览与分片下载

## 一、目标

为 Admin 文件管理页面添加**文件预览**和**分片下载**能力，支持进度条显示。

### 功能范围

| 能力 | 说明 |
|------|------|
| 文件预览 | 图片直接展示、视频/音频内嵌播放、PDF/文本内嵌查看、其他格式提示不支持预览 |
| 分片下载 | 大文件分片请求 + 进度条 + 文件名自动取 original_name |
| 后端 | 新增下载端点（Range 支持）、文件信息端点 |
| 前端 | 预览弹窗、下载按钮 + 进度条组件 |

## 二、技术方案

### 2.1 后端

#### 新增端点

| Method | Path | 说明 |
|--------|------|------|
| `GET` | `/api/admin/files/{file_id}/download` | 分片下载，支持 `Range` 请求头 |
| `GET` | `/api/admin/files/{file_id}/preview` | 获取文件预览信息（mime_type + rel_path） |

#### 下载端点设计

```python
@router.get("/{file_id}/download")
def download_file(file_id: int, ...):

    # 2. resolve_safe_path(rel_path) 拼接 UPLOAD_DIR，校验路径安全
    # 3. 读取 Range 请求头（可选）
    #    - 有 Range: 返回 206 Partial Content + Content-Range
    #    - 无 Range: 返回 200 + 完整文件
    # 4. Content-Disposition: attachment; filename="原始文件名"
    # 5. Content-Type: 根据 mime_type 映射
```

**Range 分片实现**：

```python
from fastapi import Request
from fastapi.responses import StreamingResponse
import os

file_path = resolve_safe_path(file_record.rel_path)
file_size = os.path.getsize(file_path)

range_header = request.headers.get("range")
if range_header:
    # Range: bytes=0-1023
    start, end = parse_range(range_header, file_size)
    content_length = end - start + 1

    def iter_range():
        with open(file_path, "rb") as f:
            f.seek(start)
            remaining = content_length
            while remaining > 0:
                chunk_size = min(8192, remaining)
                data = f.read(chunk_size)
                if not data:
                    break
                remaining -= len(data)
                yield data

    return StreamingResponse(
        iter_range(),
        status_code=206,
        headers={
            "Content-Range": f"bytes {start}-{end}/{file_size}",
            "Content-Length": str(content_length),
            "Accept-Ranges": "bytes",
            "Content-Disposition": f'attachment; filename="{filename}"',
        },
        media_type=mime_type,
    )
else:
    # 完整下载
    return FileResponse(
        path=file_path,
        media_type=mime_type,
        filename=filename,
    )
```

#### 分片下载实现

```typescript
async function startDownload(file: AdminFile) {
  downloading.value = true
  downloadFileName.value = file.original_name || file.rel_path
  downloaded.value = 0
  downloadTotal.value = file.size_bytes

  const CHUNK_SIZE = 1024 * 1024 // 1MB
  const total = file.size_bytes
  const chunks: Blob[] = []

  for (let start = 0; start < total; start += CHUNK_SIZE) {
    const end = Math.min(start + CHUNK_SIZE - 1, total - 1)
    const response = await fetch(
      `/api/admin/files/${file.id}/download`,
      {
        headers: { Range: `bytes=${start}-${end}` },
      }
    )
    const blob = await response.blob()
    chunks.push(blob)
    downloaded.value = Math.min(start + CHUNK_SIZE, total)
  }

  // 合并 Blob 并触发下载
  const blob = new Blob(chunks)
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = file.original_name || 'download'
  a.click()
  URL.revokeObjectURL(url)

  downloading.value = false
}
```

### 2.3 可预览文件类型判定

```typescript
const PREVIEWABLE = {
  image: ['image/jpeg', 'image/png', 'image/gif', 'image/webp'],
  video: ['video/mp4', 'video/webm', 'video/quicktime'],
  audio: ['audio/mpeg', 'audio/wav', 'audio/ogg'],
}

function canPreview(mime_type: string | null): string | false {
  if (!mime_type) return false
  for (const [type, mimes] of Object.entries(PREVIEWABLE)) {
    if (mimes.includes(mime_type)) return type
  }
  return false
}
```

## 四、注意事项

1. **安全**：下载端点需管理员鉴权（`get_current_admin`）；路径遍历保护复用 `resolve_safe_path`
2. **大文件**：分片下载每片 1MB，进度条实时更新；合并 Blob 后用 `<a download>` 触发浏览器保存
3. **预览**：复用已有的 `/api/admin/system/files/` 静态文件端点，无需新建端点
4. **CORS**：分片下载用 `fetch` + `Range` 头，同域无 CORS 问题
5. **MIME 映射**：后端下载端点根据 `File.mime_type` 设置 `Content-Type`，前端预览根据同一字段判定渲染方式
