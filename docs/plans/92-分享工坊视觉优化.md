# 92：分享工坊视觉优化

## 一、背景与目标

### 1.1 现状问题

91 完成三区域分离后，视觉细节仍存在以下问题：

| 问题 | 区域 | 说明 |
|------|------|------|
| 雷达图标注偏离顶点过远 | 雷达图 | 标注偏移量 110px，文字与对应顶点距离过远 |
| 顶点标注对齐混乱 | 雷达图 | 上下左右顶点文字一律居中，左右顶点文字溢出卡片 |
| 卡片底部标注被截断 | 雷达图 | `radarZone` 高度 420 不足，底部顶点标注超出卡片 |
| 进度条区域行距不均 | 进度条 | 标题/进度条/点评间距不当，视觉层次感差 |
| 三张图片 footer 位置偏上 | footer | footer 高度与 bottomMargin 导致品牌文字离底部过远 |

### 1.2 目标

1. 雷达图标注贴近顶点，且按顶点方位动态对齐
2. 进度条区域行间距与文字间距合理
3. footer 整体下移，贴近图片底部

## 二、雷达图文字标注优化

### 2.1 标注偏移量

`primitives.ts` `drawRadar` 标注偏移 `110 → 65`，文字更贴近顶点：

```typescript
const lp = pt(i, R + 65);
```

### 2.2 顶点动态对齐

按顶点方位角区分对齐方式，替代统一居中对齐：

```typescript
const a = angle(i);
const cosA = Math.cos(a);
const sinA = Math.sin(a);

if (Math.abs(sinA) > 0.8) {
  // 上下顶点：水平居中，垂直按方向偏移
  ctx.textAlign = "center";
  const yOffset = sinA < 0 ? -20 : 20;
  ctx.fillText(String(data[i].name), lp.x, lp.y + yOffset - 16);
  ctx.fillText(String(Math.round(Number(data[i].score) || 0)), lp.x, lp.y + yOffset + 18);
} else {
  // 左右顶点：按 x 方向左/右对齐
  ctx.textAlign = cosA > 0 ? "left" : "right";
  ctx.fillText(String(data[i].name), lp.x, lp.y - 16);
  ctx.fillText(String(Math.round(Number(data[i].score) || 0)), lp.x, lp.y + 18);
}
```

### 2.3 卡片扩容

`config.ts` `radarZone.height` `420 → 540`，防止底部顶点标注超出白色卡片。
