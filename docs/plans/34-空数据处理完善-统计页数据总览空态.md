# Step 34：空数据处理完善 — 统计页「数据总览」空态

## 一、背景

各业务页面的空数据处理整体已较完善，逐页核查结论如下：

| 页面 | 空态现状 | 结论 |
|------|---------|:----:|
| 日记页 `diary.vue` | 已有完整空态（🏸 无日记引导 + 「记录今天」按钮） | ✅ 无需改动 |
| 装备页 `gear.vue` | 已有两种空态（无装备引导 + 筛选无结果/清除筛选） | ✅ 无需改动 |
| 我的页 `mine.vue` | 设置/用户信息页，无列表数据 | ✅ 无需改动 |
| 表单页 `diary/form.vue`、`gear/form.vue` | 子列表（费用、装备）已有占位提示文案 | ✅ 无需改动 |
| 统计页 `stats.vue` | 体重管理区已有空态，但**「数据总览」汇总卡片区缺失空态** | ⚠️ 需补充 |

**问题**：当用户完全没有日记/装备/花费数据时，统计页顶部仍展示 6 张「0 值」卡片（累计打球 0 次、累计时长 0 分钟、平均强度 0.0、平均心情 0.0、总花费 ¥0、装备数 0 件），缺乏明确的空数据引导。且统计页本身无法新建日记，需引导用户跳转到日记页记录。

## 二、决策记录

| 决策点 | 结论 |
|---|---|
| 空态位置 | 「数据总览」标题下方的 6 张汇总卡片区，无数据时整体替换为 `Empty` 空态 |
| 空态判断 | 新增计算属性 `hasAnyData`：任一核心统计项（`total_sessions`/`total_duration`/`total_cost`/`total_gears`）> 0 即视为有数据 |
| 防误判 | 仅当 `!statsLoading && stats && !hasAnyData` 时显示空态，避免加载中/加载失败时误显示 |
| 跳转交互 | 「去记录」按钮用 `uni.switchTab` 跳转到日记 Tab（统计页为 tabBar 页，`switchTab` 无法带参进非 tab 页，故落地到日记列表，用户可点右下角 FAB 新建） |
| 加载状态 | 给 `getStats()` 增加 `statsLoading` ref，加载中不显示空态，`finally` 结束加载态 |
| 空态文案 | 「还没有任何打球数据，从记录第一篇日记开始吧」 |

## 三、技术方案

### 3.1 script 部分（`stats.vue`）

在 `stats` ref 之后新增：

```ts
/** 汇总统计加载中 */
const statsLoading = ref(false);

/** 是否没有任何统计数据 */
const hasAnyData = computed(() =>
  stats.value
    ? stats.value.total_sessions > 0 ||
      stats.value.total_duration > 0 ||
      stats.value.total_cost > 0 ||
      stats.value.total_gears > 0
    : false,
);

/** 跳转到日记 Tab 记录 */
function goDiary() {
  uni.switchTab({ url: "/pages/diary/diary" });
}
```

`onShow` 中为 `getStats` 增加加载状态：

```ts
onShow(() => {
  weightStore.fetchList();
  statsLoading.value = true;
  getStats()
    .then((s) => {
      stats.value = s;
    })
    .catch((e) => {
      // 未登录或失败时保持空，打印错误便于排查
      console.error("[stats] 拉取统计数据失败", e);
    })
    .finally(() => {
      statsLoading.value = false;
    });
});
```

### 3.2 template 部分（`stats.vue`）

「数据总览」区域改为条件渲染，无数据时显示空态：

```html
<!-- 汇总卡片 -->
<view class="px-4 pt-4">
  <text class="block px-1 mb-2 text-xs text-olive-light">数据总览</text>

  <!-- 空态：没有任何统计数据 -->
  <view v-if="!statsLoading && stats && !hasAnyData" class="mt-1">
    <Empty
      icon="📊"
      text="还没有任何打球数据，从记录第一篇日记开始吧"
      button-text="去记录"
      @action="goDiary"
    />
  </view>

  <!-- 统计卡片 -->
  <view v-else class="grid grid-cols-2 gap-3">
    <!-- 原 6 张卡片保持不变 -->
  </view>
</view>
```
