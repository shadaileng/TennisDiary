# 分析流程前端埋点上下文丰富化

## 一、背景与问题

`miniapp/src/pages/coach/analyze.vue` 中的分析流程埋点存在以下问题：

### 1.1 参数与结果混记

当前 `video_upload_mirage` 事件在两处触发，params 混合了请求参数和响应结果：

| 触发位置 | 当前 params | 问题 |
|----------|------------|------|
| L951 预检命中 | `{ file_id, size }` | `file_id` 是结果，`size` 是参数，混在一起 |
| L1018 上传命中 | `{ duration_ms }` | 只记耗时，完全丢弃了 `file_id`/`url` 等结果 |

### 1.2 事件链路冗余

```
L1095  analysis_started        ← 在 file_id 解析前，参数不完整
L1103  unified_analysis_start  ← 空 params，与 analysis_started 语义重叠
L1129  unified_analysis_launched ← 与 analysis_* 命名不一致
```

### 1.3 事件名重复

`analysis_failed` 在两处使用（L1161 status callback + L1187 catch block），无法区分失败来源。

### 1.4 客户端上下文不足

前端埋点的价值在于记录**后端不知道的客户端信息**，但当前多数事件 params 扁平，缺少有价值的上下文（如网络类型、文件指纹、上传方式等）。

## 二、设计原则

### 2.1 前后端分工

| 层 | 记录内容 | 说明 |
|----|---------|------|
| **前端 eventLogger** | 客户端行为 + 上下文 | 用户意图、本地文件信息、环境状态 |
| **后端审计日志** | API 调用链路 | 实际参数、响应结果、耗时（已有，102 已实现） |

前端不记录 API 参数/结果（那是后端审计日志的职责），而是记录**发起操作时的客户端状态**。

### 2.2 trace_id 关联

前端在请求头中传递 `X-Trace-Id`（已实现），后端审计日志记录此 trace_id，前后端日志通过 trace_id 串联。

### 2.3 事件命名规范

采用 `Object + Action` 的 snake_case 模式：
- `video_check`、`video_check_hit`、`video_check_miss`
- `video_upload_start`、`video_upload_success`、`video_upload_failed`
- `analysis_launch`、`analysis_launched`、`analysis_completed`、`analysis_failed`

### 2.4 params 结构规范

每个事件的 params 携带**该阶段可用的最丰富客户端上下文**，结构化分组：

```ts
{
  // 业务参数（用户选择/意图）
  mode, kind, hit_time, cuts,
  // 文件元数据（本地信息）
  video: { path, duration, size, md5 },
  // 环境状态
  network_type,
  // 操作结果（仅在有结果时）
  file_id?, analysis_id?,
  // 耗时元数据
  duration_ms?,
  // 错误信息（仅 error 级别）
  error?
}
```

## 三、事件清单

### 3.1 视频选择阶段

| Action | 级别 | 触发时机 | Params |
|--------|:----:|---------|--------|
| `choose_video` | info | 用户点击选择 | `{}` |
| `choose_video_success` | info | 选择成功 | `{ duration, size, path, source_type }` |
| `choose_video_too_long` | info | 时长超限 | `{ duration, max_duration }` |
| `choose_video_cancel` | info | 用户取消 | `{}` |
| `choose_video_empty` | error | 返回为空 | `{}` |
| `choose_video_denied` | error | 权限拒绝 | `{ error }` |
| `choose_video_privacy` | error | 隐私未配置 | `{ error }` |
| `choose_video_failed` | error | 选择失败 | `{ error }` |

| Action | 级别 | 触发时机 | Params |

| `video_fingerprint_ready` | info | 计算完成 | `{ md5, size, duration_ms }` |
| `video_fingerprint_failed` | info | 计算失败 | `{}` |

| `video_check_hit` | info | 预检命中 | `{ file_id, safe, size }` |
| `video_check_miss` | info | 预检未命中 | `{ size }` |
| `video_check_error` | info | 预检异常 | `{ error, size }` |
| `video_upload_start` | info | 上传开始 | `{ size, method: "whole"\|"chunked", chunk_size? }` |
| `video_upload_success` | info | 上传完成 | `{ file_id, size, duration_ms, mirage }` |
| `video_upload_failed` | error | 上传失败 | `{ error, size, duration_ms }` |
| `video_upload_canceled` | info | 用户取消 | `{ uploaded_bytes, total_bytes }` |
