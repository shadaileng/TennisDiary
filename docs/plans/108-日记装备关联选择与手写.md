# Step 108：日记装备关联选择与手写

## 一、目标

日记表单的「配套装备」模块支持两种输入方式：
1. **从已有装备选择**：下拉选择 gear store 中的装备，自动填充名称
2. **手动输入**：保留原有手动输入名称和体验的方式

## 二、现状分析

### 2.1 当前实现

**文件**：`pages/diary/form.vue`

- 装备关联是纯文本输入（name + feeling）
- 无装备列表选择功能
- 数据结构：`GearUseInput { name: string, feeling: string }`

### 2.2 装备数据源

**文件**：`stores/gear.ts`

- `gears: Gear[]` — 已有装备列表
- `fetchList()` — 拉取装备列表（GET /api/gears）
- Gear 接口：`{ id, category, name, buy_date, price, feeling, photo }`

## 三、UI 设计

```
配套装备
+ 添加
┌─────────────────────────────────┐
│ 📋 从已有装备选择               │  ← 点击展开 picker
├─────────────────────────────────┤
│ 球拍名称（自动填充）            │  ← 可修改
│ 本次使用体验（选填）            │
│                             ×   │
└─────────────────────────────────┘
```

### 交互流程

1. 点击「从已有装备选择」→ 弹出 action-sheet/picker 显示装备名称列表
2. 选择后自动填充 `gears[i].name`，用户可修改
3. 保留手动输入框，两种方式兼容
4. 已装备列表为空时隐藏选择器，仅显示手动输入

## 四、实现方案

### 4.1 涉及文件

| 文件 | 变更 |
|------|------|
| `pages/diary/form.vue` | 新增装备选择交互 |

### 4.2 具体改动

#### 模板变更

在「配套装备」卡片中新增选择器：

```vue
<!-- 从已有装备选择 -->
<view v-if="gearStore.gears.length > 0" class="form-gear-select" @tap="showGearPicker">
  <text class="form-hint">📋 从已有装备选择</text>
</view>
```

#### 脚本变更

1. 导入 `useGearStore`
2. `onLoad` 时调用 `gearStore.fetchList()`
3. 新增 `showGearPicker()` 方法，使用 `uni.showActionSheet` 展示装备列表
4. 选择后自动填充 `gears[i].name`

### 4.3 关键代码

```typescript
import { useGearStore } from "@/stores";

const gearStore = useGearStore();

onLoad(() => {
  gearStore.fetchList();
});

function showGearPicker(index: number) {
  const names = gearStore.gears.map(g => g.name);
  uni.showActionSheet({
    itemList: names,
    success: (res) => {
      form.gears[index].name = names[res.tapIndex];
    }
  });
}
```
