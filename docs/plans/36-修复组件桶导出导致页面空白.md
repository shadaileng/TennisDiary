# Step 36：修复组件桶导出导致页面空白

## 一、背景

### 1.1 问题现象

日记 / 装备 / 统计三个 Tab 页面**整体空白**，且**空状态（含游客引导）也不显示**；「我的」页正常。

### 1.2 根因定位

对比编译产物（`dist/build/mp-weixin/`）发现：

- `diary.json` / `gear.json` / `stats.json` 的 `usingComponents` 均为 **`{}`**（空）；
- 但对应的 `.wxml` 里引用了自定义组件 `<empty>`、`<line-chart>`、`<popup>`。

微信小程序中，**WXML 引用了未在 `usingComponents` 声明的自定义组件标签**时，该节点无法解析、渲染为空，导致整页空白。

进一步排查根因：这些页面统一通过**桶导出** `@/components`（`src/components/index.ts`）批量引入组件，例如：

```ts
import { Empty } from "@/components";            // 桶导出
import { Empty, LineChart, Popup } from "@/components";
import { EmojiScale, Seg } from "@/components";
```

uni-app 的 mp-weixin 编译器对**经桶重导出的组件**无法识别并自动注册进 `usingComponents`；只有**直接按文件引入**（`@/components/Empty.vue`）才会正确注册。因此「我的」页（未用自定义组件）正常，其余使用组件的页面全部空白。

### 1.3 目标

将页面中所有自定义组件的引入方式从「桶导出」改为「直接按文件导出」，使编译产物 `usingComponents` 正确注册，恢复页面与空态展示。

## 二、技术方案

将以下页面中 `@/components` 桶导入改为直接导入对应 `.vue` 文件：

| 文件 | 修改前 | 修改后 |
|---|---|---|
| `src/pages/diary/diary.vue` | `import { Empty } from "@/components"` | `import Empty from "@/components/Empty.vue"` |
| `src/pages/gear/gear.vue` | `import { Empty } from "@/components"` | `import Empty from "@/components/Empty.vue"` |
| `src/pages/stats/stats.vue` | `import { Empty, LineChart, Popup } from "@/components"` | 拆分为三条独立 `import` |
| `src/pages/diary/form.vue` | `import { EmojiScale, Seg } from "@/components"` | 拆分为两条独立 `import` |
| `src/pages/gear/form.vue` | `import { Seg } from "@/components"` | `import Seg from "@/components/Seg.vue"` |

> `src/components/index.ts`（桶文件）**保留**，供 H5 端或无需 mp 编译的场景使用；小程序业务页统一改为直接文件导入。
