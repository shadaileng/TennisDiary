# Step 62：Admin 事件日志页详情弹窗

## 一、背景

`59-小程序事件锚点与线上事件日志` 实现了事件日志的采集与后台 API，管理端 `event-logs.vue` 仅展示列表，无法查看详情。

## 二、变更内容

### 2.1 列表交互优化

- 表格行增加 `cursor-pointer` 样式，点击可展开详情
- 新增「用户」列，展示 `user_id` 对应的昵称（通过 `getUser` API 懒加载）

### 2.2 详情弹窗

点击行后弹出全屏遮罩弹窗，展示：
- **基本信息**：时间、级别（带颜色标签）、类型、用户（头像+昵称）、操作链路（trace_id）、业务动作、页面、上报时间
- **消息**：原始消息文本
- **堆栈信息**：错误堆栈（黑色背景绿色字体）
- **设备信息**：JSON 格式的设备详情
- **扩展字段**：JSON 格式的 extra 数据

### 2.3 用户信息懒加载

- 点击行时才调用 `getUser(userId)` 获取用户信息
- 本地缓存已加载的用户，避免重复请求
- 未登录用户（`user_id` 为 null）展示 `--`

### 2.4 时间格式化

- `formatClientTime`：事件 `client_time`（毫秒时间戳）→ 本地时间
- `formatServerTime`：`created_at`（秒级时间戳）→ 本地时间

## 三、修改文件

| 文件 | 变更 |
|------|------|
| `admin/src/views/system/event-logs.vue` | 新增详情弹窗、用户列、懒加载用户信息 |
