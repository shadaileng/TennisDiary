# Step B1-10：统计汇总接口

## 一、目标

实现 `GET /api/stats` 统计数据汇总接口，聚合当前用户的日记、装备、分析三类数据，返回概览指标。

## 二、前置条件

- B1-3 完成（Diary / Gear / Analysis 模型）
- B1-4 完成（Pydantic Schemas：`StatsResponse`）
- B1-5 完成（JWT 鉴权 `get_current_user`）
- B1-6/B1-7 完成（日记、装备接口已就绪，可写入测试数据）

## 三、接口设计

| 端点 | 方法 | 说明 | 鉴权 |
|---|---|---|---|
| `/api/stats` | GET | 当前用户统计数据汇总 | 是 |

### 3.1 指标计算

所有指标仅统计 `user_id == current_user.id` 的数据：

| 字段 | 来源 | 计算 |
|---|---|---|
| `total_sessions` | Diary | 日记条数 |
| `total_duration` | Diary | duration 求和（分钟） |
| `avg_intensity` | Diary | intensity 均值（保留 2 位） |
| `avg_mood` | Diary | mood 均值（保留 2 位） |
| `total_cost` | Diary | 每条 costs JSON 内 amount 求和（保留 2 位） |
| `total_gears` | Gear | 装备条数 |
| `total_analyses` | Analysis | 分析条数 |
| `avg_score` | Analysis | score 均值（保留 2 位） |

空数据（无日记/无分析）时均值返回 0.0，不报错。

## 四、详细执行步骤

### 4.1 路由模块（`app/routers/stats.py`，新增）

- 查询三类数据计数/聚合（用 `func.count` / `func.sum` / `func.avg` 或内存聚合）
- `costs` 为 JSON 文本，需逐条 `json.loads` 累加 amount
- 组装 `StatsResponse` 返回

### 4.2 注册路由（`app/main.py`）

- `from app.routers import stats`
- `app.include_router(stats.router)`
