# Step 56：小程序前端视觉样式与交互适配改造

## 一、目标

对照参考源码（Web 版），对小程序前端**前三个 Tab 页**（日记、装备、统计）进行视觉样式与交互适配改造，解决以下问题：

1. **视觉还原度不足**：Hero 区域缺少装饰性图标和背景效果，整体视觉层次平淡
2. **交互体验缺失**：缺少金额隐私切换按钮（MoneyToggle）、缺少 sticky 筛选栏
3. **样式细节差异**：卡片阴影、过渡动画、按下反馈等微交互未对齐
4. **小程序适配问题**：部分 CSS 效果在小程序环境中渲染异常

**改造范围**（不做/延后）：
- 打卡热力图（MonthHeatmap/YearHeatmap）→ 延后 Phase 3 实现
- 技术评分雷达图（Radar）→ 依赖 AI 分析，Phase 4 实现
- 摄影感 Hero 背景图 → 小程序暂不支持外部图片资源，延后
- NTRP 评级显示 → 依赖 AI 分析，Phase 4 实现
- 订单截图 OCR 识别 → 依赖 AI Key，Phase B2 实现

## 二、现状盘点

### 2.1 参考源码关键设计

| 元素 | 参考源码实现 |
|------|-------------|
| Hero 装饰 | Racket/TennisBall/Shirt SVG 图标 + 模糊光晕（blur-xl） |
| 金额切换 | `MoneyToggle` 组件（眼睛图标，全局记忆状态） |
| 筛选栏 | `sticky top-[52px]` + `backdrop-blur` 毛玻璃效果 |
| 卡片阴影 | `shadow-[0_1px_8px_rgba(23,27,20,0.04)]` 极淡阴影 |
| 按下反馈 | `active:scale-[0.99]` + `transition-transform` |
| FAB 阴影 | `shadow-[0_6px_20px_rgba(200,218,43,0.5)]` 青柠色阴影 |

### 2.2 当前 miniapp 实现

| 元素 | 当前状态 | 问题 |
|------|---------|------|
| Hero 装饰 | 纯色背景，无装饰图标 | 视觉单调 |
| 金额切换 | 无 MoneyToggle 按钮 | 隐私开关仅影响显示，无快捷切换 |
| 筛选栏 | 普通布局，无 sticky | 滚动时筛选条件不可见 |
| 卡片阴影 | 无阴影或阴影过强 | 缺少层次感 |
| 按下反馈 | `active:opacity-90` + `transform: scale(0.99)` | 小程序兼容性待验证 |
| FAB 阴影 | `shadow-lg` 标准阴影 | 颜色不够鲜明 |

### 2.3 小程序技术约束

| 约束 | 影响 | 解决方案 |
|------|------|---------|
| 不支持内联 SVG | 装饰图标无法直接使用 | 改用 emoji 或内联 CSS 形状 |
| 不支持 `backdrop-blur` | 毛玻璃效果失效 | 改用半透明纯色背景 |
| 不支持 `box-shadow` 复杂值 | 自定义阴影可能失效 | 使用小程序支持的阴影语法 |
| `transform: scale` 兼容性 | 部分机型表现不一致 | 简化为 `opacity` 变化 |
| CSS 变量支持有限 | Tailwind 主题 token 正常，自定义变量需测试 | 仅使用 Tailwind 配置的颜色 |

## 三、决策记录

| 决策点 | 结论 |
|---|---|
| Hero 装饰图标 | 使用 emoji（🎾🏸）替代 SVG 图标，定位绝对位置 |
| 模糊光晕效果 | 使用 `opacity` + 大半径圆形 view 模拟，不用 `blur` |
| 金额切换按钮 | 新增 `MoneyToggle` 组件，状态存入 `settingsStore`（与 `hideAmounts` 联动） |
| Sticky 筛选栏 | 使用 `position: sticky` + 半透明背景（不用 `backdrop-blur`） |
| 卡片阴影 | 使用小程序支持的 `box-shadow` 语法（`0 1px 8px rgba(...)`） |
| 按下反馈 | 统一使用 `opacity` 变化（`active:opacity-90`），去掉 `transform: scale` |
| FAB 阴影 | 使用青柠色阴影 `0 6px 20px rgba(200,218,43,0.5)` |
| 过渡动画 | 使用 `transition-opacity` 替代 `transition-transform` |

## 四、技术方案

### 4.1 新增组件：`MoneyToggle.vue`

**功能**：金额显示/隐藏切换按钮，状态与 `settingsStore.hideAmounts` 联动。

**实现**：
```vue
<template>
  <view
    class="w-7 h-7 rounded-full flex items-center justify-center active:opacity-60 transition-opacity"
    :class="settingsStore.hideAmounts ? 'bg-white/15 text-white/80' : 'bg-paper text-olive-light'"
    @tap="toggle"
  >
    <!-- 眼睛图标：SVG path -->
    <svg v-if="!settingsStore.hideAmounts" class="w-4 h-4" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
      <path d="M1 12s4-8 11-8 11 8 11 8-4 8-11 8-11-8-11-8z"/>
      <circle cx="12" cy="12" r="3"/>
    </svg>
    <svg v-else class="w-4 h-4" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
      <path d="M17.94 17.94A10.07 10.07 0 0 1 12 20c-7 0-11-8-11-8a18.45 18.45 0 0 1 5.06-5.94M9.9 4.24A9.12 9.12 0 0 1 12 4c7 0 11 8 11 8a18.5 18.5 0 0 1-2.16 3.19m-6.72-1.07a3 3 0 1 1-4.24-4.24"/>
      <line x1="1" y1="1" x2="23" y2="23"/>
    </svg>
  </view>
</template>

<script setup lang="ts">
import { useSettingsStore } from "@/stores";

const settingsStore = useSettingsStore();

function toggle() {
  settingsStore.hideAmounts = !settingsStore.hideAmounts;
}
</script>
```

**位置**：`miniapp/src/components/MoneyToggle.vue`

**导出**：`miniapp/src/components/index.ts`

### 4.3 装备页改造：`pages/gear/gear.vue`

#### 4.3.1 Sticky 筛选栏

**改造方案**：将 Hero + 筛选栏包裹在 sticky 容器中。

```html
<view class="sticky top-0 z-10 bg-paper/95">
  <!-- Hero -->
  <view class="m-4 mb-2 rounded-hero bg-olive p-5 overflow-hidden">
    <!-- 装饰光晕 -->
    <view class="absolute -right-8 -bottom-10 w-36 h-36 rounded-full bg-lime opacity-10" />
    <!-- 装饰图标 -->
    <text class="absolute -right-2 -top-3 text-5xl opacity-20 rotate-12 select-none">👕</text>
    <!-- 内容 -->
    ...
    <MoneyToggle class="ml-3 shrink-0" />
  </view>

  <!-- 筛选 chips（仅在有数据时显示） -->
  <view v-if="gearStore.gears.length > 0" class="px-4 space-y-1.5 pb-3">
    <!-- 分类筛选 -->
    <scroll-view scroll-x class="w-full whitespace-nowrap">
      <view class="inline-flex gap-1.5 py-0.5">
        <view
          v-for="c in catOptions"
          :key="c"
          class="inline-block shrink-0 rounded-full px-3 py-1.5 text-xs font-medium transition-opacity"
          :class="catFilter === c ? 'bg-lime text-olive' : 'bg-white text-olive-light border border-paper'"
          @tap="catFilter = c"
        >{{ c }}</view>
      </view>
    </scroll-view>
    <!-- 月份筛选 -->
    <scroll-view scroll-x class="w-full whitespace-nowrap">
      <view class="inline-flex gap-1.5 py-0.5">
        <view
          v-for="mo in monthOptions"
          :key="mo"
          class="inline-block shrink-0 rounded-full px-3 py-1.5 text-xs font-medium transition-opacity"
          :class="monthFilter === mo ? 'bg-olive text-lime' : 'bg-white text-olive-light border border-paper'"
          @tap="monthFilter = mo"
        >{{ mo === "全部" ? "全部月份" : mo.replace("-", "/") }}</view>
      </view>
    </scroll-view>
  </view>
</view>
```

**注意**：小程序的 `position: sticky` 需要父容器有明确的高度限制，否则可能不生效。需要测试验证。

## 七、风险与注意事项

1. **Sticky 兼容性**：小程序 `position: sticky` 需要父容器有明确高度，否则可能不生效。需要逐项测试。
2. **阴影语法**：小程序支持 `box-shadow: 0 1px 8px rgba(...)` 语法，但复杂值可能需要简化。
3. **Emoji 渲染**：不同机型 emoji 渲染可能不一致，需要测试。
4. **过渡动画**：小程序对 `transition` 支持有限，可能需要使用 `animation` 替代。
