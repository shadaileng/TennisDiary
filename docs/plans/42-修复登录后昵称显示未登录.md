# 42：修复登录成功后昵称仍显示「未登录」

## 一、背景与根因定位

### 1.1 问题现象

登录成功后，「我的」页昵称区域仍显示 **「未登录」**，尽管按钮等已切换为已登录态（编辑资料）。

### 1.2 根因

后端新建用户时 `nickname` 默认为空串（`app/models/user.py` 的 `nickname = Column(String(64), default="")`）。「我的」页旧逻辑直接用 `authStore.user?.nickname || "未登录"` 兜底，导致**已登录但昵称未设置**的用户（新注册）被误判为「未登录」。

```vue
<!-- 修复前 miniapp/src/pages/mine/mine.vue -->
<text class="profile-nickname">{{ authStore.user?.nickname || "未登录" }}</text>
```

## 二、目标

- 未登录：显示「未登录」
- 已登录：优先昵称；昵称为空显示「微信用户」，不再误报未登录

## 三、方案设计

新增 computed `profileName`，依据登录态与用户昵称综合判断：

```ts
const profileName = computed(() => {
  if (!authStore.isLoggedIn || !authStore.user) return "未登录";
  return authStore.user.nickname || "微信用户";
});
```

模板改用 `{{ profileName }}`。

## 四、验收标准

1. 新用户登录后，「我的」页显示「微信用户」而非「未登录」。
2. 用户设置昵称后，显示其昵称。
3. 登出后恢复显示「未登录」。
4. `pnpm type-check` 通过。

## 五、实施步骤

1. `mine.vue` 新增 computed `profileName`，模板引用。
2. 验证 `pnpm type-check` 通过。
