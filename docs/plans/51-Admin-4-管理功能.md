# Phase Admin-4：管理功能

## 一、目标

实现用户管理、角色管理、管理员管理页面，对接后端管理API。

## 二、已完成内容

- 实现用户管理页面（列表、查看、删除）
- 实现角色管理页面（列表、新建、编辑、删除、权限配置）
- 实现管理员管理页面（列表、新建、编辑、重置密码、启用/禁用、删除）
- 实现通用组件（Table、Pagination、Modal）
- 封装用户、角色、管理员API
