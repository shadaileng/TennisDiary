# 75-4：分析报告落库与历史查询

## 一、背景与目标

总纲 75-B2 §4.5：AI 评分代理（75-1）返回六维报告后需**落库持久化**，供 Phase 4 小程序「电子教练」报告页历史回看与重复查看。现有 `Analysis` ORM 模型与 `analyses` 表（初始迁移已建）已具备基础字段，但**缺少用户端历史查询接口**与 `video_url` 字段。

| 目标 | 说明 |
|------|------|
| 用户端接口 | `POST /api/analyses`（落库）/ `GET /api/analyses`（历史列表）/ `GET /api/analyses/{id}`（详情）/ `DELETE /api/analyses/{id}` |
| 字段补全 | `Analysis` 增加 `video_url`（视频文件相对路径，75-2 返回） |
| 迁移 | Alembic 增量迁移新增 `video_url` 列 |
| 落库时机 | 小程序端在 AI 分析成功后调用 `POST /api/analyses` 持久化（与参考版 `db.analyses.add` 流程一致） |
| 鉴权 | 统一 `X-Auth-Token` + `get_current_user`，仅访问本人数据 |

## 二、现状

| 项 | 现状 |
|----|------|
| ORM 模型 | `app/models/analysis.py` `Analysis`：`id / user_id / date / kind / mode / score / summary / ntrp / report(JSON文本) / thumb / highlights(JSON) / created_at / updated_at`，**无 `video_url`** |
| 表 | `analyses` 已在初始迁移 `3a79ce8c1f19` 建表，`report`/`highlights` 为 Text 存 JSON |
| Schema | `schemas.py` 已有 `AnalysisCreate / AnalysisResponse / AnalysisReportSchema / DimensionScore / ImprovementItem`（与 75-B2-Admin 对齐） |
| 管理端 | `routers/admin/analyses.py` 已有列表/详情/删除，但**无用户端接口** |
| 用户端路由 | 无 `routers/analyses.py`；`stats.py` 已统计 `total_analyses / avg_score`（依赖该表） |

## 三、关键契约

- **落库入参**（`POST /api/analyses`，沿用现有 `AnalysisCreate`）：

```json
{
  "date": "2026-08-13",
  "kind": "正手",
  "mode": "single",
  "score": 76,
  "summary": "整体发力流畅",
  "ntrp": "3.5",
  "report": {"score":76,"summary":"...","ntrp":"3.5","dimensions":[...],"rhythm":"...","strengths":[...],"improvements":[...]},
  "thumb": "videos/xxx_f0.jpg",
  "highlights": ["videos/xxx_f1.jpg"],
  "video_url": "videos/xxx.mp4"
}
```

- **出参**（沿用现有 `AnalysisResponse`，含 `id / user_id / created_at`；`report/highlights` 返回结构化 JSON，兼容历史脏数据）；
- **历史列表**：`GET /api/analyses`，分页 `offset/limit`，按 `created_at` 倒序，仅当前用户；
- **详情**：`GET /api/analyses/{id}`，仅本人；不存在/越权返回 404；
- **删除**：`DELETE /api/analyses/{id}`，仅本人。

## 四、详细方案

### 4.1 模型与迁移（`server/app/models/analysis.py` + Alembic）

```python
video_url = Column(String(255), nullable=True)  # 视频文件相对路径（75-2 返回）
```

- 生成增量迁移：`alembic revision --autogenerate -m "add video_url to analyses"`；
- `updated_at` 已有，无需新增。

### 4.2 Schema 微调（`server/app/schemas/schemas.py`）

- `AnalysisCreate` 增加可选 `video_url: str | None = None`；
- `AnalysisResponse` 增加 `video_url: str | None = None`（`from_attributes`）。

### 4.3 用户端路由（新建 `server/app/routers/analyses.py`）

`APIRouter(prefix="/api/analyses", tags=["analyses"])`，全部依赖 `get_current_user`：

| 端点 | 说明 |
|------|------|
| `POST ""` | 落库：`AnalysisCreate` → 新建 `Analysis`（`created_at=time.time()`，`report/highlights` 转 JSON 文本）→ 返回 `AnalysisResponse` |
| `GET ""` | 历史列表：`offset/limit` 分页 + 总数，`created_at` 倒序 |
| `GET "/{analysis_id}"` | 详情：解析 `report/highlights` JSON 返回结构化对象 |
| `DELETE "/{analysis_id}"` | 删除：仅本人，404 兜底 |

复用 `diaries.py` 模式（`_get_owned_*` 越权 404），JSON 解析容错参考 `admin/analyses.py` `_parse_json_field`。

### 4.4 注册（`server/app/main.py`）

`from app.routers import analyses` + `app.include_router(analyses.router)`。
