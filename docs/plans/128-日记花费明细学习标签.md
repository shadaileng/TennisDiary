# Step 128：日记花费明细学习标签

## 一、目标

日记表单「花费明细」卡片新增**本地学习式高频费用快捷标签**：
- 点击标签可直接新增一条费用明细（名称自动填好、金额留空待录入）
- 已存在同名明细时不重复添加，仅聚焦已有行并轻提示
- 本地持久化记录各费用名目**使用频次**，保存日记后频次 +1
- 首次填写的费用类型自动加入候选池
- 界面始终展示频次最高的 6 项

## 二、需求来源与澄清结论

- 原始需求：「小程序端日记表单，花费明细卡片，添加"场地"、"饮料"等快速输入选项」
- 澄清①：快速选项集合由实现方拟定
- 澄清②（点击行为 A+B）：无同名明细 → 直接新增一行名称自动填好、金额留空进入输入；已有同名 → 不重复添加，仅轻提示/聚焦已有行金额
- 澄清③（最终需求）：改为**本地 store 存储 + 频次学习**方案 —— 保存之后更新标签频次，首次填写的费用类型加入候选，界面显示频次最高的 6 项

## 三、现状分析

### 3.1 花费明细卡片（`pages/diary/form.vue`）

- 卡片头：标题「花费明细」+「＋ 添加」链接（`@tap="addCost"`）
- 空态提示 `.form-hint`（`v-if="form.costs.length === 0"`）文案「如：场地费 / 教练费 / 网球」
- 费用行 `.form-cost-row`：名称 input（`:value="c.name"`）+ `.form-cost-amount` 金额区（¥ 前缀 + digit input 绑定 `c.amount`）+ 删除「×」（`@tap="removeCost(i)"`）
- 合计区 `.form-total`（`costTotalText`）
- `interface CostItemInput { name: string; amount: number }`
- `save()` 过滤空行后构造 `body.costs`，调用 `diaryStore.create/update`

### 3.2 持久化模式范本（`stores/settings.ts`）

## 四、方案设计

### 4.1 数据模型

本地持久化结构：`Array<{ name: string; count: number }>`（候选池）。

- **频次累计**：保存日记成功后，本次实际保存的每个费用名目 `count + 1`（去重后逐名）
- **首次入池**：候选池中不存在的 name 自动以 `count: 1` 加入（保存后）
- **不做减法**：删除日记/编辑改名不扣频次，学习曲线单增，避免误扣

### 4.2 默认种子策略

纯学习模式首装时池为空 → 界面无任何快捷标签，与「加场地/饮料快速选项」初衷冲突。故内置**默认种子**保证首用体验：

- 池为空（storage 无数据）时初始化合并种子
- 种子 `["场地费", "教练费", "网球", "饮料", "手胶", "穿线"]`（常量为 `DEFAULT_COST_PRESETS`），count 从 1 起
- 后续真实填写项随频次增长自然把低使用种子挤出 top6

### 4.3 展示规则

- getter `topPresets`：按 count 降序取前 6 的 name 数组
- 频次相同需稳定 tie-break：采用**名称字典序**（简单稳定）
- 种子保证池恒非空，标签区常驻
- 原 `.form-hint` 空态文案与标签区功能重叠，有标签区时移除空态提示（改为展示提示性辅助文案的兜底）

### 4.4 交互（A+B 保留）

- 新增 `focusCostIdx = ref<number | null>(null)`
- 金额 input `:focus="focusCostIdx === i"` + `@blur` 清空
- handler `tapCostPreset(preset)`：
  - 已存在同名行（`findIndex` ≥ 0）→ 聚焦已有行金额 + `uni.showToast("已添加「xx」")`
  - 不存在 → `push({ name: preset, amount: 0 })` 后聚焦新行金额（`focusCostIdx = costs.length - 1`）

### 4.5 频次累计触发点

`save()` 内 create/update 成功后（resolve 之后、导航之前）调用 store action `recordUsed(names)` —— names 取 `body.costs` 去重后的 name 列表，成功后立即 persist。失败路径不累计。

### 4.6 样式

- 标签区 `flex-wrap` + gap，胶囊贴近 `.pill--inactive`（浅底 `var(--color-page-bg)` + `$color-olive-light` 字）
- **不用** `.pill--active`（避免与训练时长单选混淆）
- 颜色走 CSS/SCSS 变量适配主题
- 置于卡片头之下、明细行之上，常驻展示

### 5.2 store 设计（`stores/costTags.ts`）

```typescript
interface CostTagEntry { name: string; count: number }

state: { list: CostTagEntry[] }

getters:
  topPresets: (state) => 按 count 降序、count 相同时 name 升序，取前 MAX 个的 name[]

actions:
  init(): storage 无数据 → 以 DEFAULT_COST_PRESETS 初始化种子（count=1）并 persist
          有数据 → 反序列化恢复（损坏则回退种子）
  recordUsed(names: string[]): 逐名 count +1；不存在则以 count=1 入池；persist
  persist(): 写回 storage
```

### 5.3 form.vue 改动要点

- 卡片头下、明细行上插入常驻标签区 `v-for="p in costTagsStore.topPresets"`，点击 `tapCostPreset(p)`
- 新增 `costTagsStore` 实例与 `focusCostIdx`
- `save()` 成功后调用 `costTagsStore.recordUsed(...)`
- 金额 input 增加 `:focus` 与 `@blur` 绑定
- `onLoad` 编辑回填后重置 `focusCostIdx`
