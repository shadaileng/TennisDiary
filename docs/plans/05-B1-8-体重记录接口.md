# Step B1-8：体重记录接口

## 一、目标

实现 `/api/weights` 体重记录的增、查、删接口，复用 B1-6/B1-7 范式（强制 `user_id` 归属校验）。

## 二、前置条件

- B1-3 完成（WeightRecord 模型 `app/models/weight.py`）
- B1-4 完成（Pydantic Schemas：`WeightCreate` / `WeightResponse`）
- B1-5 完成（JWT 鉴权 `get_current_user`）

## 三、接口设计

> 注：主计划 5.4 接口清单中体重记录**无 PUT 更新**，仅有 GET/POST 列表/添加 + DELETE/{id}。本步骤据此实现，不提供更新接口。

| 端点 | 方法 | 说明 | 鉴权 |
|---|---|---|---|
| `/api/weights` | GET | 当前用户体重记录列表（按 date 倒序） | 是 |
| `/api/weights` | POST | 添加体重记录 | 是 |
| `/api/weights/{id}` | DELETE | 删除体重记录 | 是 |

### 3.1 关键约束

- 所有查询强制 `user_id == current_user.id`，越权访问返回 404。
- `bust` / `waist` / `hip` 为可空围度字段。
- `created_at` 入库为 Unix 时间戳（`time.time()`）。

## 四、详细执行步骤

### 4.1 路由模块（`app/routers/weights.py`，新增）

- `list_weights`：`filter_by(user_id=...).order_by(WeightRecord.date.desc())`
- `create_weight`：`WeightCreate` → 构造 `WeightRecord`，`commit`/`refresh` 后返回 `WeightResponse`
- `delete_weight`：经 `_get_owned_weight` 校验归属后删除，不存在或越权返回 404

### 4.2 注册路由（`app/main.py`）

- `from app.routers import weights`
- `app.include_router(weights.router)`
