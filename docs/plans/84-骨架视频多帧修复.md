## 一、问题现象

用户上传视频后，AI 分析完成，报告页的「骨架视频」切换播放时：
- 视频只有 **1 帧**（时长 ~0.3s，`nb_frames: 1`），并非原视频全部采样帧的动画
- 本地文件路径：`server/data/uploads/videos/{uid}/{base}_skeleton.mp4`
- 对应的骨架帧文件 `_sk0.jpg` ~ `_skN.jpg` 均已正确生成（7 张），只是编码时丢失了 6 张

## 二、根因分析

### 2.1 症状定位

```bash
ffprobe <skeleton.mp4>
# nb_frames: 1, duration: 0.335s（应为 ~2.3s, 7 帧）
```

骨架帧文件正常生成（7 张），说明 `analyze_frames` 的循环和 `draw_skeleton` 无误。
问题出在 `encode_skeleton_video` 的 ffmpeg 命令。

### 2.2 根因：ffmpeg concat demuxer 的静态图片行为

**错误命令**（当前实现）：
```bash
ffmpeg -y -f concat -safe 0 -i list.txt \
  -vf "fps=3,scale=trunc(iw/2)*2:trunc(ih/2)*2" \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart out.mp4
```

concat demuxer 将每个输入文件视为**无限长视频流**。当输入是静态 JPEG 时，每张图被当作"持续无限"的帧，ffmpeg 只取第一张图的第一帧作为输出，其余全部丢弃 → 输出 `nb_frames: 1`。

**验证**：
```bash
# concat 方式 → 1 帧 ✗
ffmpeg -f concat -i list.txt -vf fps=3 ... out.mp4  # nb_frames=1

# -framerate + %d 通配符 → 7 帧 ✓
ffmpeg -framerate 3 -i "frame_%d.jpg" ... out.mp4   # nb_frames=7
```

### 2.3 修复方案

改用 ffmpeg 的 **input image sequence** 语法：
- 骨架帧命名格式：`{base}_sk{i:04d}.jpg`（4 位零填充，支持 `%04d` 通配符）
- ffmpeg 命令：`-framerate {fps} -i "{path}/{base}_sk%04d.jpg"`
- 移除 concat 列表文件的创建和清理逻辑

## 三、代码改动

### 3.1 `server/app/services/pose_service.py`

**改动点 1：骨架帧命名**（`analyze_frames` 函数，约第 406 行）

```python
# 修改前
sk_path = os.path.join(video_dir, f"{base}_sk{i}.jpg")

# 修改后（4 位零填充，匹配 %04d 通配符）
sk_path = os.path.join(video_dir, f"{base}_sk{i:04d}.jpg")
```

**改动点 2：`encode_skeleton_video` 函数**

```python
# 修改前：concat demuxer
list_path = os.path.join(os.path.dirname(out_path), f".{os.path.basename(out_path)}.concat.txt")
with open(list_path, "w", encoding="utf-8") as f:
    for p in skeleton_paths:
        f.write(f"file '{os.path.abspath(p)}'\n")
cmd = [ffmpeg, "-y", "-f", "concat", "-safe", "0", "-i", list_path, ...]
# finally: os.unlink(list_path)

# 修改后：-framerate + %04d 通配符
# 骨架帧已按 {base}_sk%04d.jpg 命名，直接传给 ffmpeg
cmd = [
    ffmpeg, "-y",
    "-framerate", str(max(1.0, min(30.0, fps))),
    "-i", os.path.join(os.path.dirname(skeleton_paths[0]), f"{os.path.splitext(os.path.basename(skeleton_paths[0]))[0]}_%04d.jpg"),
    "-vf", "scale=trunc(iw/2)*2:trunc(ih/2)*2",
    "-c:v", "libx264", "-pix_fmt", "yuv420p", "-movflags", "+faststart",
    out_path,
]
# 无需列表文件，移除 finally 清理逻辑
```
