# 89：分享工坊条件管线模式重构

## 一、背景与目标

### 1.1 现状问题

| 问题 | 严重度 | 说明 |
|------|:------:|------|
| `drawShareCard` 职责过重 | 🔴 | 230 行，包含三模板完整逻辑 + 数据过滤 + 布局计算 |
| 工具函数重复定义 | 🟡 | `monthKey`/`todayStr`/`fmtDuration` 等 6 个函数与 `utils/index.ts` 完全重复 |
| double-draw 问题 | 🔴 | `share.vue` 调用两次 `drawShareCard`，第一次仅获取高度 |
| 数据聚合重复 | 🟡 | `monthDiaries` 在 `drawShareCard` 和 `genCaption` 中各算一次 |
| 无测试覆盖 | 🔴 | miniapp 无任何测试，无法验证布局正确性 |
| 魔法数字泛滥 | 🟡 | 布局参数硬编码，无命名常量 |

### 1.2 目标

1. **条件管线模式**：将 Canvas 绘制拆分为有序阶段 → 条件步骤的管线
2. **单一职责**：每个步骤独立、可组合、可测试
3. **高度计算分离**：纯函数 `measureHeight()` 替代 double-draw
4. **Playwright 回归测试**：三模板 × 多场景的布局截图对比

### 2.2 核心类型

```typescript
// 管线上下文（每个步骤共享）
interface PipelineContext {
  tpl: ShareTemplate
  data: ShareData
  config: typeof PIPELINE_CONFIG
  // 预计算结果（步骤间传递）
  monthDiaries: Diary[]
  latestDiary?: Diary
  latestAnalysis?: Analysis
}

// 绘制步骤
interface DrawStep {
  name: string
  condition: (ctx: PipelineContext) => boolean
  measure?: (y: number, ctx: PipelineContext) => number
  execute: (ctx: CanvasRenderingContext2D, pipe: PipelineContext, y: number) => number
}

// 布局阶段
interface DrawStage {
  name: string
  steps: DrawStep[]
}
```

### 2.3 管线执行器

```typescript
class DrawPipeline {
  private stages: DrawStage[] = []
  
  addStage(stage: DrawStage): this {
    this.stages.push(stage)
    return this
  }
  
  // 预计算高度（不执行绘制）
  measureHeight(pipe: PipelineContext): number {
    let y = pipe.config.content.top
    for (const stage of this.stages) {
      for (const step of stage.steps) {
        if (step.condition(pipe) && step.measure) {
          y = step.measure(y, pipe)
        }
      }
    }
    return y + pipe.config.footer.height
  }
  
  // 执行绘制
  execute(ctx: CanvasRenderingContext2D, pipe: PipelineContext): number {
    const H = this.measureHeight(pipe)
    ctx.fillStyle = PAPER
    ctx.fillRect(0, 0, W, H)
    
    let y = pipe.config.content.top
    for (const stage of this.stages) {
      for (const step of stage.steps) {
        if (step.condition(pipe)) {
          y = step.execute(ctx, pipe, y)
        }
      }
    }
    
    footer(ctx, H)
    return H
  }
}
```

### 4.2 Node Canvas 渲染

```typescript
// tests/share-canvas/helpers.ts
import { createCanvas } from '@napi-rs/canvas'

export async function renderShareCard(
  tpl: ShareTemplate,
  data: ShareData,
): Promise<{ image: string; height: number }> {
  const pipe = buildContext(tpl, data)
  const pipeline = createPipeline()
  const height = pipeline.measureHeight(pipe)
  
  const canvas = createCanvas(1080, height)
  const ctx = canvas.getContext('2d')
  pipeline.execute(ctx, pipe)
  
  return {
    image: canvas.toBuffer('image/png').toString('base64'),
    height,
  }
}
```
