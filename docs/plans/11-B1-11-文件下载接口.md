# Step B1-11：文件下载接口

## 一、目标

实现 `GET /api/files/{filename}` 文件下载接口，供前端按相对路径获取已上传的图片/视频等文件，并完成**路径穿越防护**与**归属校验**（仅能下载当前用户拥有的文件）。

## 二、前置条件

- B1-3 完成（Diary / Gear 模型，分别含 `photo` 字段引用上传文件）
- B1-5 完成（JWT 鉴权 `get_current_user`）
- 文件存储约定：上传文件位于 `UPLOAD_DIR`（默认 `./data/uploads`），引用路径为相对 `UPLOAD_DIR` 的路径，如 `images/photo.jpg`（与 `Gear.photo` 存储值一致）

## 三、接口设计

| 端点 | 方法 | 说明 | 鉴权 |
|---|---|---|---|
| `/api/files/{filename}` | GET | 下载文件（filename 为相对 UPLOAD_DIR 的路径） | 是 |

`filename` 为路径参数（如 `images/photo.jpg`），**不含**前导 `/`。

### 3.1 安全规则

1. **路径穿越防护**：对 `filename` 做 `os.path.normpath`，解析后的绝对路径必须严格位于 `UPLOAD_DIR` 之内；含 `..` 或绝对路径一律拒绝（404）。
2. **归属校验**：该相对路径必须被当前用户拥有的某条记录（Gear 或 Diary 的 `photo` 字段）引用，否则拒绝（404）。
3. **文件存在性**：目标文件不存在返回 404。
4. **Content-Type**：根据扩展名推断（`images/*` → `image/jpeg` 等），无法识别时回退 `application/octet-stream`。

## 四、详细执行步骤

### 4.1 路由模块（`app/routers/files.py`，新增）

- `from fastapi.responses import FileResponse`
- 解析并校验 `filename` → 计算绝对路径 `abs_path`
- 校验 1：穿越防护
- 校验 2：归属校验（查询 `Gear` / `Diary` 中 `user_id == current_user.id` 且 `photo` 含该相对路径）
- 校验 3：文件存在性
- 返回 `FileResponse(abs_path, media_type=...)`

### 4.2 注册路由（`app/main.py`）

- `from app.routers import files`
- `app.include_router(files.router)`
