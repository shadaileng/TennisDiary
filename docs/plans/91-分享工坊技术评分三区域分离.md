# 91：分享工坊技术评分三区域分离

## 一、背景与目标

### 1.1 现状问题

89 重构后，技术评分内容由 `stages/techScore.ts` 单一步骤（`radar-hexagon`）一次性绘制，问题：

| 问题 | 严重度 | 说明 |
|------|:------:|------|
| 单一步骤职责过重 | 🔴 | 雷达图、进度条、总结全部塞在一个 step 内，高度计算与绘制耦合 |
| 无法单独验证 | 🔴 | 无法对雷达图/进度条/总结三个区域分别截图回归 |
| 条件分支复杂 | 🟡 | 有/无维度、有/无总结多条件叠加，可读性差 |

### 1.2 目标

将技术评分图片内容区从上到下拆为三个独立区域（Stage）：

1. **雷达图区域**（`radarStage`）：六边形雷达图 + 空态/大球降级
2. **进度条区域**（`progressStage`）：六维评分进度条 + 点评文字
3. **总结区域**（`summaryStage`）：分析总结文本

并为每个区域新增独立 Playwright 回归测试（合计 4 个用例）。

## 二、区域划分设计

### 2.1 布局（从上到下）

```
┌───────────────────────────────────────┐
│  header（Y: 0-420）                   │
├───────────────────────────────────────┤
│  ┌─────────────────────────────┐      │
│  │  雷达图区域（Y: 480-940）    │      │
│  │  六边形雷达图（居中）         │      │
│  └─────────────────────────────┘      │
│  ┌─────────────────────────────┐      │
│  │  进度条区域（Y: 980 起）      │      │
│  │  维度名 + 分值 + 进度条 + 点评│      │
│  └─────────────────────────────┘      │
│  │  总结区域（总结文本居中）      │      │
│  ┌─────────────────────────────┐      │
│  │  footer                     │      │
│  └─────────────────────────────┘      │
└───────────────────────────────────────┘
```

### 2.2 Stage 拆分

`stages/techScore.ts` 导出三个 Stage：

| Stage | name | 条件 | 内容 |
|-------|------|------|------|
| `radarStage` | `techScore-radar` | 技术评分模板 | 空态卡 / 六边形雷达图 / 大球降级 |
| `progressStage` | `techScore-progress` | 技术评分 + ≥3 维度 | 维度名 + 分值 + 进度条 + 点评 |
| `summaryStage` | `techScore-summary` | 技术评分 + `analysis.summary` | 总结文本居中 |

### 2.3 高度计算

三个 Stage 分别提供 `measure()`，由 `measureHeight()` 汇总：

```typescript
// radarStage.measure
const dims = (r.dimensions || []).slice(0, 6);
const dimListH = dims.length * cfg.progressZone.itemHeight;
const summaryH = r.summary ? cfg.summaryZone.height + 40 : 0;
const totalH = cfg.radarZone.height + dimListH + summaryH + 40;
return cfg.cardTop + totalH;
```

### 2.4 白色卡片包裹

内容区整体下移（`cardTop` 470→480），白色卡片统一包裹雷达图 + 进度条区域，总结文本显示在卡片下方，视觉更聚焦：

```typescript
white(ctx, 70, cfg.cardTop, 940, totalH);   // 卡片包裹雷达图 + 进度条
drawRadar(ctx, cfg.radar.cx, cfg.radar.cy, cfg.radar.radius, dims);
```

## 三、关键配置

`config.ts` 中 `PIPELINE_CONFIG.techScore`：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `cardTop` | 480 | 白色卡片顶部 Y |
| `radar.cx/cy` | `W/2` / 680 | 雷达图圆心 |
| `radar.radius` | 120 | 雷达图半径 |
| `radarZone.top/height` | 470 / 420 | 雷达图区域 |
| `progressZone.top` | 920 | 进度条区域起点 |
| `progressZone.itemHeight` | 200 | 每维度行高 |
| `summaryZone.height/lineHeight` | 200 / 48 | 总结区域 |
| `scoreBallCard` | `{x:70,y:470,w:940,h:600}` | 大球降级卡 |

## 四、Playwright 回归测试

### 4.1 测试辅助：单区域渲染

`tests/share-canvas/helpers.ts` 新增 `renderTechScoreZone(zone, data)`，可只渲染指定区域（header + 单 stage + footer），用于独立截图：

```typescript
export async function renderTechScoreZone(
  zone: "radar" | "progress" | "summary",
  data: ShareData,
): Promise<{ image: Buffer; height: number }> {
  const pipe = buildContext("技术评分", data, DEFAULT_MOOD, DEFAULT_INTENSITY);
  const pipeline = new DrawPipeline().addStage(headerStage);
  if (zone === "radar") pipeline.addStage(radarStage);
  else if (zone === "progress") pipeline.addStage(progressStage);
  else pipeline.addStage(summaryStage);
  pipeline.addStage(footerStage);
  // measureHeight + execute ...
}
```

### 4.2 新增用例（4 个）

| 用例 | 渲染方式 | 快照 |
|------|---------|------|
| 技术评分-雷达图区域 | `renderTechScoreZone("radar", 6维度)` | `tech-score-radar-zone.png` |
| 技术评分-进度条区域 | `renderTechScoreZone("progress", 6维度)` | `tech-score-progress-zone.png` |
| 技术评分-总结区域 | `renderTechScoreZone("summary", 6维度)` | `tech-score-summary-zone.png` |
| 技术评分-三区域完整渲染 | `renderShareCard("技术评分", 6维度)` | `tech-score-full.png` |
