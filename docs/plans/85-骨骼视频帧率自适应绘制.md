# 85：骨骼视频帧率自适应绘制

## 一、背景与目标

当前骨骼视频的帧率计算方式为 `fps = 帧数 / 时长`，没有考虑原始视频的实际帧率。这导致：
1. 高帧率视频（如30fps）的骨骼动画播放速度比原始视频慢很多
2. 每帧都进行姿态推理，计算量较大

**目标**：
1. 获取原始视频的帧率
2. 根据帧率调整骨骼绘制频率（减少计算量）
3. 让骨骼视频播放速度与原始视频一致

## 二、现状分析

| 项 | 现状 |
|----|------|
| 视频帧率获取 | `video_service.py` 只获取时长，不获取帧率 |
| 骨骼视频帧率 | `pose_service.py` 第415行：`fps = (len(skeleton_paths) / duration) if duration else 2.0` |
| 绘制频率 | 每帧都进行姿态推理和骨架绘制 |
| 编码帧率 | `encode_skeleton_video` 接收 fps 参数，clamp 到 [1.0, 30.0] |

## 三、详细方案

### 3.1 后端：获取视频帧率

**文件**：`server/app/services/video_service.py`

新增 `probe_frame_rate` 函数：

```python
def probe_frame_rate(path: str) -> float:
    """探测视频帧率：优先 ffprobe，回退默认 30fps
    
    返回浮点数帧率（如 29.97, 30.0, 60.0）
    """
    ffprobe = shutil.which("ffprobe")
    if ffprobe:
        proc = subprocess.run(
            [
                ffprobe,
                "-v", "error",
                "-select_streams", "v:0",
                "-show_entries", "stream=r_frame_rate,avg_frame_rate",
                "-of", "default=nw=1:nk=1",
                path,
            ],
            capture_output=True,
            timeout=30,
        )
        if proc.returncode == 0:
            # 解析帧率，格式如 "30000/1001" 或 "30"
            frame_rate_str = proc.stdout.decode().strip()
            if "/" in frame_rate_str:
                num, den = frame_rate_str.split("/")
                return float(num) / float(den)
            return float(frame_rate_str)
    return 30.0  # 默认帧率
```

修改 `process_video` 返回值，增加 `frame_rate` 字段：


### 3.2 修复：骨骼视频帧率计算（v1.1.0）

**问题**：原实现直接使用原始视频帧率（如30fps），导致骨骼视频播放速度加快。

**原因分析**：
- 原视频30fps，10秒，抽取了8帧
- 骨骼视频帧率设置为30fps
- 骨骼视频播放时长 = 8帧 / 30fps ≈ 0.27秒（原视频10秒）

**修复方案**：骨骼视频帧率应让播放时长与原视频一致

```python
# 修复前（错误）
if frame_rate and frame_rate > 0:
    effective_fps = min(frame_rate, 30.0)

# 修复后（正确）
effective_fps = (len(skeleton_paths) / duration) if duration else 2.0
```

**验证**：8帧 / 10秒 = 0.8fps → 播放时长 = 8帧 / 0.8fps = 10秒 ✓

### 3.3 绘制频率优化策略

为了减少计算量，可以根据帧率决定绘制频率：

```python
# 根据帧率决定绘制频率
if frame_rate and frame_rate >= 30:
    # 高帧率视频（≥30fps），每5帧绘制一次
    draw_interval = 5
elif frame_rate and frame_rate >= 24:
    # 中帧率视频（≥24fps），每4帧绘制一次
    draw_interval = 4
else:
    # 低帧率或未知帧率，每帧绘制
    draw_interval = 1

# 在循环中使用
for i, frame in enumerate(frames):
    if i % draw_interval != 0 and i != len(frames) - 1:
        # 跳过绘制，但仍然进行姿态推理（如果需要metrics）

        results.append({"landmarks": landmarks or []})
        continue
```
