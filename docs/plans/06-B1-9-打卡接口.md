# Step B1-9：打卡接口

## 一、目标

实现 `/api/checkin` 训练营打卡的查询与签到接口，复用 B1-6~B1-8 范式（强制 `user_id` 归属校验）。

## 二、前置条件

- B1-3 完成（Checkin 模型 `app/models/checkin.py`）
- B1-4 完成（Pydantic Schemas：`CheckinCreate` / `CheckinResponse`）
- B1-5 完成（JWT 鉴权 `get_current_user`）

## 三、接口设计

| 端点 | 方法 | 说明 | 鉴权 |
|---|---|---|---|
| `/api/checkin` | GET | 当前用户打卡记录列表（按 date 倒序） | 是 |
| `/api/checkin` | POST | 签到（同一 user+course+date 不重复） | 是 |

### 3.1 关键约束

- 所有查询强制 `user_id == current_user.id`，越权访问返回 404。
- 打卡为幂等签到：同一用户同一课程同一日期仅保留一条记录（重复签到返回已有记录，不报错）。
- `created_at` 入库为 Unix 时间戳（`time.time()`）。

## 四、详细执行步骤

### 4.1 路由模块（`app/routers/checkin.py`，新增）

- `list_checkins`：`filter_by(user_id=...).order_by(Checkin.date.desc())`
- `create_checkin`：`CheckinCreate` → 先查是否已存在（同 user_id+course_id+date），存在则返回已有；否则新建并 `commit`/`refresh` 后返回 `CheckinResponse`

### 4.2 注册路由（`app/main.py`）

- `from app.routers import checkin`
- `app.include_router(checkin.router)`
