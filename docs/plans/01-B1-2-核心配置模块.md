# Step B1-2：核心配置模块

## 一、目标

创建 FastAPI 应用的配置中心和数据库连接模块，为后续所有模块提供统一配置入口和数据库会话依赖。

## 二、前置条件

- B1-1 完成（项目骨架 + 依赖安装）

## 三、详细执行步骤

### 3.1 创建 `app/core/config.py` — 应用配置

使用 Pydantic `BaseSettings` 模式（或简单类 + `os.getenv`），统一管理所有配置项：

| 配置项 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| APP_NAME | — | Tennis Diary API | 应用名 |
| APP_VERSION | — | 1.0.0 | 版本号 |
| DEBUG | DEBUG | false | 调试模式 |
| DATABASE_URL | DATABASE_URL | sqlite:///./data/tennis_diary.db | 数据库连接 |
| JWT_SECRET | JWT_SECRET | change-me-in-production-please | JWT 密钥 |
| JWT_ALGORITHM | — | HS256 | JWT 算法 |
| JWT_EXPIRATION_HOURS | JWT_EXPIRATION_HOURS | 720 | Token 有效期（30天） |
| WX_APPID | WX_APPID | (空) | 微信小程序 AppID |
| WX_SECRET | WX_SECRET | (空) | 微信小程序 Secret |
| AI_API_KEY | AI_API_KEY | (空) | AI API Key |
| AI_BASE_URL | AI_BASE_URL | https://dashscope.aliyuncs.com/compatible-mode/v1 | AI 接口地址 |
| AI_MODEL | AI_MODEL | qwen-vl-max | AI 模型名 |
| UPLOAD_DIR | UPLOAD_DIR | ./uploads | 文件上传目录 |
| MAX_UPLOAD_SIZE_MB | MAX_UPLOAD_SIZE_MB | 100 | 最大上传大小(MB) |

**实现方式**：使用简单的 `Settings` 类，构造函数中通过 `os.getenv()` 读取环境变量并设默认值。

### 3.2 创建 `app/core/database.py` — 数据库连接

使用 SQLAlchemy 的声明式模式：

1. 解析 `DATABASE_URL`，提取 SQLite 文件路径
2. 确保数据文件所在目录存在（`os.makedirs`）
3. 创建 `engine`（SQLite 需 `check_same_thread=False`）
4. 创建 `SessionLocal`（sessionmaker）
5. 创建 `Base`（declarative_base）
6. 导出 `get_db()` FastAPI 依赖（yield session 并在 finally 中关闭）

### 3.3 验证

```python
# 测试配置可导入
python -c "from app.core.config import settings; print(settings.DATABASE_URL)"

# 测试数据库引擎可创建
python -c "from app.core.database import engine, Base; print('engine created:', engine)"

# 测试 get_db 依赖可用
python -c "from app.core.database import get_db; print('get_db:', get_db)"
```

## 四、产出物

| 文件 | 说明 |
|---|---|
| `app/core/config.py` | Settings 配置类，所有环境变量集中管理 |
| `app/core/database.py` | SQLAlchemy 引擎 + Session + Base + get_db 依赖 |

## 五、验收标准

- [ ] `from app.core.config import settings` 可正常导入，配置值正确
- [ ] `from app.core.database import engine, Base, get_db` 可正常导入
- [ ] `Base.metadata.create_all(engine)` 不报错（此时无表，执行无效果）
- [ ] SQLite 文件可在 `data/` 目录下创建
