# 90：小程序 UI 布局视觉回归测试

## 一、背景与目标

### 1.1 现状问题

| 问题 | 严重度 | 说明 |
|------|:------:|------|
| Canvas 组件无测试覆盖 | 🔴 | RadarChart/LineChart 等 Canvas 组件无任何视觉回归测试 |
| 布局调整无法自动验证 | 🔴 | 修改样式后无法自动检测视觉差异 |
| 无基线截图管理 | 🟡 | 缺少标准化的截图对比流程 |

### 1.2 目标

1. **视觉回归测试**：为 RadarChart/LineChart 创建 Playwright 截图对比测试
2. **多项目配置**：扩展 playwright.config.ts 支持 share-canvas/components/pages 多项目
3. **Skill 集成**：集成 playwright-visual-regression skill 获取最佳实践

## 二、测试结构

### 2.1 目录结构

```
miniapp/tests/
├── share-canvas/              # 已有（8 个测试）
│   ├── share-canvas.spec.ts
│   ├── helpers.ts
│   └── share-canvas.spec.ts-snapshots/
├── components/                # 新增
│   ├── RadarChart.spec.ts     # 雷达图视觉回归
│   ├── LineChart.spec.ts      # 折线图视觉回归
│   └── helpers.ts             # 测试工具函数
└── pages/                     # 预留
    └── ...
```

### 2.2 测试场景

| 组件 | 测试场景 | 数据 | 验证点 |
|------|---------|------|--------|
| RadarChart | 6 维度雷达图 | 6 个维度数据 | 网格/多边形/标签 |
| RadarChart | 3 维度雷达图 | 3 个维度数据 | 最小有效数据 |
| RadarChart | <3 维度占位 | 2 个维度 | 占位文本显示 |
| LineChart | 正常折线 | 5 个数据点 | 折线/面积/标签 |
| LineChart | 单数据点 | 1 个数据点 | 单点渲染 |
| LineChart | 空数据占位 | 0 个数据点 | 占位文本显示 |

## 三、Playwright 配置扩展

### 3.1 多项目配置

```typescript
// playwright.config.ts
export default defineConfig({
  projects: [
    { name: "share-canvas", testDir: "./tests/share-canvas" },
    { name: "components", testDir: "./tests/components" },
  ],
});
```

### 3.2 截图对比参数

```typescript
expect: {
  toHaveScreenshot: {
    maxDiffPixelRatio: 0.01,  // 1% 容差
    threshold: 0.2,           // 像素级阈值
  },
},
```

## 四、实施步骤

| Step | 任务 | 说明 |
|:----:|------|------|
| 1 | 更新 playwright.config.ts | 添加 components 项目 |
| 2 | 创建 tests/components/helpers.ts | 测试工具函数 |
| 3 | 创建 RadarChart.spec.ts | 3 个测试场景 |
| 4 | 创建 LineChart.spec.ts | 3 个测试场景 |
| 5 | 生成基准截图 | pnpm test:update-snapshots |
| 6 | 验证测试通过 | pnpm test |

## 五、测试命令

```bash
cd miniapp

# 运行所有测试
pnpm test

# 仅运行组件测试
pnpm test --project components

# 更新基线截图
pnpm test:update-snapshots
```
